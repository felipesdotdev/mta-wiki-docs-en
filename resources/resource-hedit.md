# Resource : Hedit

The MTA Ingame Handling Editor (known as 'hedit') is an open source resource that was created in 2010 and has been included in the official MTA resources package since 2021.

You can see and download the latest version on the Hedit page of [official resources **GitHub repository**](https://github.com/multitheftauto/mtasa-resources/tree/master/%5Bgameplay%5D/hedit) or download it directly from the latest package at [https://mirror-cdn.multitheftauto.com/mtasa/resources/mtasa-resources-latest.zip](https://mirror-cdn.multitheftauto.com/mtasa/resources/mtasa-resources-latest.zip).
