# How you can help

Multi Theft Auto has loads of areas in which you can help us. In turn, we'll be more than happy to help you get started with any ideas you have, help test them and - if they're good enough - release them to the whole community. This page outlines the key areas you could do something in, of course, there are many things we've not thought of, so think outside the box!

## Coding for MTA:SA

- Become a patch contributor by sending [pull requests](https://github.com/multitheftauto/mtasa-blue/pulls) to MTA, containing requested features or bugfixes: [Coding guidelines](mta://scripting/concepts/coding-guidelines.md)

## Translating MTA:SA

- Translate MTA to your native language on Crowdin at [https://multitheftauto.crowdin.com/](https://multitheftauto.crowdin.com/)

## Scripting

- Become a contributor to MTA's official resources, read more about them here: [Default resources](mta://reference/misc/default-resources.md)

- Create and [publish](https://community.multitheftauto.com/) a gamemode or useful script

- [Scripting Introduction](mta://scripting/concepts/scripting-introduction.md)

- ["Programming in Lua" Manual](https://www.lua.org/pil/index.html)

- Make a general purpose resource that provides useful functions to other resources.

## Mapping

- Create and [publish](https://community.multitheftauto.com/) a map for an existing gamemode, with the map editor.

- [Map Editor Manual](mta://resources/editor.md)

## Web development

- Create your own system for statistics - using the [PHP SDK](mta://tutorials/php-sdk.md) as a basis. Join the [MTA Discord](https://discord.com/invite/mtasa) (or [development Discord](https://discord.gg/GNN6PRtTnu)) for help.

## Documentation

Before you make changes check out: [Editing Guidelines](https://wiki.multitheftauto.com/wiki/Help:Editing_Guidelines) and [Specific Templates](https://wiki.multitheftauto.com/wiki/Help:MTA_Wiki_Specific_Templates)

- Finish documentation for [Incomplete functions](https://wiki.multitheftauto.com/wiki/Category:Incomplete) - ask in #mta.scripting if you're not sure of something.

- Add examples to [functions & events missing examples](https://wiki.multitheftauto.com/wiki/Category:Needs_Example) - please **test** them, and again, ask if you need help.

- Review and verify [pages that need checking](https://wiki.multitheftauto.com/wiki/Category:Needs_Checking) - make sure highlighted issues are solved before removing pages from the category.

- Expand the pages that explain [MTA core concepts](https://wiki.multitheftauto.com/wiki/Category:Scripting_Concepts).

- Write [tutorials](https://forum.multitheftauto.com/forum/123-tutorials/) to help new people.

- Translate the wiki pages so people from other countries can get started in MTA too.

- Create documentation for undocumented functions and events [Undocumented Items](mta://reference/misc/undocumented-items.md)

- Keep 'changes in' [current work-in-progress: [https://wiki.multitheftauto.com/wiki/Changes_in_1.6](https://wiki.multitheftauto.com/wiki/Changes_in_1.6)] for future releases updated.

## Quality Assurance

- [Report issues](https://github.com/multitheftauto/mtasa-blue/issues) with the mod, make sure to do a search on the already reported issues first.

- Test and confirm existing reported issues.

- Use the newest build of MTA to detect and report new bugs, by going to 'Settings', 'Advanced', 'Update build type' and choosing 'Nightly' or get it regularly [from here](https://nightly.multitheftauto.com/).

- Any bugs which are related to a scripting function / event and present in the main release (rather than nightlies), document that bug by adding a [warning](https://wiki.multitheftauto.com/wiki/Help:MTA_Wiki_Specific_Templates) to the wiki page to save other scripters a lot of time.
