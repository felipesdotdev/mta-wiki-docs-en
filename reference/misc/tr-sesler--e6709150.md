# Tr/Sesler

Bunlar, [playSoundFrontEnd](mta://scripting/shared/functions/playsoundfrontend.md) ile kullanabileceğiniz ses [idleridir](mta://reference/misc/id--474ae526.md).

- - **0 - 20** Selection sounds

- **27 - 30** Bullet sounds

- **32 - 33** Selection sounds

- **34** Radio static

- **35** Stop Radio static

- **37 - 38** Tick

- **40** Selection sounds

- **41 - 42** Tick (no ammo)

- **43 - 45** Race countdown

- **46** Repair

- **47** White noise static

- **48** Stop White noise static

- **49** Static short

- **101** Countdown/selection
