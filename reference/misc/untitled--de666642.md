# Category : Игрок

Класс *Player* представляет людей, контролируемых клиентами. Объект клиента, создаётся когда клиент подключается к серверу, и уничтожается когда отключается. Игроков нельзя создать или уничтожить каким-либо другим способом.

Тип элемента этого класса - **"player"**.
