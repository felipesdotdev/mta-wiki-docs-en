# Таблица

Таблица - это тип хранения данных подобный массиву. Они по большей части используются для хранения большого объема данных. Также могут быть ассоциативными массивами, но в качестве индекса могут быть применены не только строки, но в частности и [элементы](https://wiki.multitheftauto.com/wiki/RU/Element).
