# ZH-CN/Main Page

**欢迎来到 [Multi Theft Auto](mta://reference/misc/multi-theft-auto.md) Wiki。**您可以在这里查询与 Multi Theft Auto 游戏及开发有关的任何相关信息。

您可以**创建地图及游戏模式**；帮助我们**编写脚本 API 文档**、**示例代码**及**教程**；或是将**游戏过程中所发现的 Bugs 告诉我们**。

如果您在编写脚本时遇到了问题，欢迎随时通过[Discord 或 IRC](mta://reference/misc/places-to-chat.md)联系我们。
