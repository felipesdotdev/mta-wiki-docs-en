# Elemento/Console

A classe Server Console representa o console do servidor.

O tipo de elemento desta classe é: **"console"**.

## Comandos

No console do servidor você pode usar vários comandos diferentes, afetando os jogadores usando o servidor. Note que somente comandos de console podem ser usados, e que alguns comandos não podem ser usados através do console in-game, somente através do console do Servidor.

Você pode ver todos os últimos comandos disponíveis usando o comando "help" na janela de console do servidor.
