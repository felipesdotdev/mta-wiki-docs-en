# DE/table

Eine Tabelle ist ein reihenartige Datenspeicherung. Sie werden meist für grössere Datenspeicherungen verwendet.  

Tabellen können nicht nur mit Zahlen, sondern auch mit anderen Datentypen, wie zum Beispiel mit einem String oder mit MTA [Elemente](mta://reference/misc/elements.md) indiziert werden.  

Hier ist eine Liste mit den Standard-Manipulationsfunktionen für Tabellen in Lua.
