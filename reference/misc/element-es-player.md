# ES/Elemento/Player

La clase de elemento player reprecenta un ped controlado por un jugador. Un objeto player es creado cuando un cliente se conecta al servidor y es destruido cuando el cliente sale. Los objetos player no pueden ser creados o destruidos de ninguna otra manera.

El tipo de elemento de esta clase es **"player"**.
