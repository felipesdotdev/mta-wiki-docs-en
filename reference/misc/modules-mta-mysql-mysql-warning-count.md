# Modules/MTA-MySQL/mysql warning count

|  | This function is provided by the external module MTA-MySQL . You must install this module to use this function. |
| --- | --- |
|  |  |

Returns the last query number of warnings

## Syntax

```
int mysql_warning_count ( MySQLConnection handler )
```

### Required arguments

- **handler:** A valid MySQL link

### Returns

An integer showing the number of warning of the last query
