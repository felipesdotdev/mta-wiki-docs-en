#### Общие функции

- [xmlCopyFile](https://wiki.multitheftauto.com/wiki/RU/xmlCopyFile) - *копирует всё содержимое определённого узла в XML-документе в новый файл документа*

- [xmlCreateChild](https://wiki.multitheftauto.com/wiki/RU/xmlCreateChild) - *создаёт новый дочерний узел в узле XML*

- [xmlCreateFile](https://wiki.multitheftauto.com/wiki/RU/xmlCreateFile) - *создаёт новый XML-документ, который впоследствии можно сохранить в файл с помощью [xmlSaveFile](https://wiki.multitheftauto.com/wiki/RU/xmlSaveFile)*

ДО ВЕРСИИ 1.0.0 :

- [xmlCreateSubNode](https://wiki.multitheftauto.com/index.php?title=RU/xmlCreateSubNode&action=edit&redlink=1) - *создаёт подузел для указанного XML узла*

- [xmlFindSubNode](https://wiki.multitheftauto.com/index.php?title=RU/xmlFindSubNode&action=edit&redlink=1) - *возвращает именованный подузел определённого XML узла*

- [xmlDestroyNode](https://wiki.multitheftauto.com/wiki/RU/xmlDestroyNode) - *удаляет узел XML из дерева узлов XML*

- [xmlFindChild](https://wiki.multitheftauto.com/wiki/RU/xmlFindChild) - *возвращает именованный дочерний узел узла XML*

- [xmlLoadFile](https://wiki.multitheftauto.com/wiki/RU/xmlLoadFile) - *загружает XML-файл и возвращает узел, указав конкретный путь к файлу*

- [xmlLoadString](https://wiki.multitheftauto.com/index.php?title=RU/xmlLoadString&action=edit&redlink=1) - *создаёт XML узел из строкового ввода*

- [xmlNodeGetAttribute](https://wiki.multitheftauto.com/wiki/RU/xmlNodeGetAttribute) - *возвращает атрибут узла в файле конфигурации*

- [xmlNodeGetAttributes](https://wiki.multitheftauto.com/wiki/RU/xmlNodeGetAttributes) - *возвращает все аттрибуты выбранного XML узла*

- [xmlNodeGetChildren](https://wiki.multitheftauto.com/wiki/RU/xmlNodeGetChildren) - *возвращает все дочерние элементы определенного XML узла или определенного дочернего узла*

- [xmlNodeGetName](https://wiki.multitheftauto.com/wiki/RU/xmlNodeGetName) - *возвращает имя тега указанного XML узла*

- [xmlNodeGetParent](https://wiki.multitheftauto.com/wiki/RU/xmlNodeGetParent) - *возвращает родительский узел XML узла*

- [xmlNodeGetValue](https://wiki.multitheftauto.com/index.php?title=RU/xmlNodeGetValue&action=edit&redlink=1) - *читает значения тегов в файлах XML*

- [xmlNodeSetAttribute](https://wiki.multitheftauto.com/wiki/RU/xmlNodeSetAttribute) - *редактирует атрибуты узла в файле конфигурации*

- [xmlNodeSetName](https://wiki.multitheftauto.com/wiki/RU/xmlNodeSetName) - *задает имя тега указанного XML узла*

- [xmlNodeSetValue](https://wiki.multitheftauto.com/index.php?title=RU/xmlNodeSetValue&action=edit&redlink=1) - *присваивает значения тегам в файлах XML*

- [xmlSaveFile](https://wiki.multitheftauto.com/wiki/RU/xmlSaveFile) - *сохраняет загруженный файл XML*

- [xmlUnloadFile](https://wiki.multitheftauto.com/wiki/RU/xmlUnloadFile) - *выгружает XML файл из памяти*
