# Category : Элемент

**Element** (элемент) - общий класс, представляющий почти все внутриигровые [субъекты](https://wiki.multitheftauto.com/index.php?title=RU/entity&action=edit&redlink=1).

Любой другой тип элементов может быть создан как абстрактный элемент, без ссылки на различные игровые [субъекты](https://wiki.multitheftauto.com/index.php?title=RU/entity&action=edit&redlink=1). Например, элементы **resource** и **map** создаются при загрузке ресурсов и карт соответственно. Их цель - группировка создаваемых ими же субъектов, которые являются по отношении к ним дочерними.

Доступны такие обыденные функции, как запрос типа элемента и списка элементов определенного типа, операция уничтожения для удаления элемента и игровых субъектов, с которыми он связан (за исключением некоторых неуничтожаемых, например, элементов клиента), хранение и запрос [данных элементов](https://wiki.multitheftauto.com/index.php?title=RU/element_data&action=edit&redlink=1), и многие другие характерные операции.

Все элементы хранятся внутри [древовидной структуры](https://wiki.multitheftauto.com/wiki/RU/Element_tree), и в сущности каждый элемент, отличный от **root**, имеет родительский элемент, который может являться элементами **root** (корень), **resource**, **map** или другими. Это сделано сугубо для возможности определения сферы действия вызываемой функции.
