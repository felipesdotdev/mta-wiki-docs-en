# NL/console

Mta Console Commands [Dutch]

Let op ! doe ingame een / voor het woord!

Commands: Hiermee zie je alle commands.

disconnect: Hiermee ga je naar de serverlist en leave je de server!.

exit of quit: Hiermee sluit je mta af!.

help: Hiermee zie je consolehelp.

ignore <naam>: Hiermee negeer je iemand.

maps: Hiermee zie je alle server maps!

msg <naam> <bericht>: Hiermee pm je iemand.[Werkt niet op sommige gamemodes!]

pm <naam> <bericht>: Hiermee pm je iemand.

nick <naam>: Hiermee verander je jou nick/schuilnaam.

reconnect: Logt uit en dan terug in op de server.

say <bericht>: Hiermee zeg je iets in chat. [Je kan ook gewoon T drukken en chatten]

time: Zegt de servertijd/Jou pc tijd.

ver: Versie van mta server en client.
