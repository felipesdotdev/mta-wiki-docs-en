# Скины персонажей

- [Страница со всеми скинами](mta://reference/misc/all-skins-page.md) - Не рекомендуется, если у вас медленный интернет.

- [Страница с особыми скинами](mta://reference/misc/special-skins-page.md) - Новые скины, которые стали доступны начиная с MTA версии 1.1
