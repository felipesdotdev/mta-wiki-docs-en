# Standard DGS Font Names

These are the standard fonts that are used in DGS and can be accessed functions [dgsGetFont](mta://scripting/client/functions/dgsgetfont.md) and [dgsSetFont](mta://scripting/client/functions/dgssetfont.md).
"default"
"default-bold"
"clear"
"arial"
"sans"
"pricedown"
"bankgothic"
"diploma"
"beckett"

- Available font properties and previews (ruined arabic word means that font doesn't support RTL languages)
