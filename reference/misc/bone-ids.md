# Bone IDs

Ped bone IDs

 

Bone numbers

#### Lua table of boneIDs which can be used on [getElementBonePosition](mta://scripting/client/functions/getelementboneposition.md) function.

```
boneIDs = {
    0, 1, 2, 3, 4, 5, 6, 7, 8, 21,
    22, 23, 24, 25, 26, 31, 32, 33,
    34, 35, 36, 41, 42, 43, 44, 51,
    52, 53, 54, 201, 301, 302
}
```

- **0:** BONE_ROOT

- **1:** BONE_PELVIS1

- **2:** BONE_PELVIS

- **3:** BONE_SPINE1

- **4:** BONE_UPPERTORSO

- **5:** BONE_NECK

- **6:** BONE_HEAD2

- **7:** BONE_HEAD1

- **8:** BONE_HEAD

- **21:** BONE_RIGHTUPPERTORSO

- **22:** BONE_RIGHTSHOULDER

- **23:** BONE_RIGHTELBOW

- **24:** BONE_RIGHTWRIST

- **25:** BONE_RIGHTHAND

- **26:** BONE_RIGHTTHUMB

- **31:** BONE_LEFTUPPERTORSO

- **32:** BONE_LEFTSHOULDER

- **33:** BONE_LEFTELBOW

- **34:** BONE_LEFTWRIST

- **35:** BONE_LEFTHAND

- **36:** BONE_LEFTTHUMB

- **41:** BONE_LEFTHIP

- **42:** BONE_LEFTKNEE

- **43:** BONE_LEFTANKLE

- **44:** BONE_LEFTFOOT

- **51:** BONE_RIGHTHIP

- **52:** BONE_RIGHTKNEE

- **53:** BONE_RIGHTANKLE

- **54:** BONE_RIGHTFOOT

- **201:** BONE_BELLY

- **301:** BONE_RIGHTBREAST

- **302:** BONE_LEFTBREAST
