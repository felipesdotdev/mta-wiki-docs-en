# Element/DX font

The DX font class represents a custom typeface which can be used in the [Drawing functions](mta://scripting/concepts/client-scripting-functions.md). A DX font is created with [dxCreateFont](mta://scripting/client/functions/dxcreatefont.md) and can be used as a parameter in [dxDrawText](mta://scripting/client/functions/dxdrawtext.md).

The element type of this class is **"dx-font"**.
