# Category : Звук

Элемент *Sound* представляет собой пользовательский звук, отправляемый клиенту с использованием параметра файла внутри "[meta.xml](https://wiki.multitheftauto.com/wiki/RU/Meta.xml)".

Может быть создан c помощью функций "[playSound](https://wiki.multitheftauto.com/index.php?title=RU/playSound&action=edit&redlink=1)" и "[playSound3D](https://wiki.multitheftauto.com/wiki/RU/playSound3D)" и изменяться следующими функциями:

- [setElementPosition](https://wiki.multitheftauto.com/wiki/RU/setElementPosition)

- [setElementDimension](https://wiki.multitheftauto.com/index.php?title=RU/setElementDimension&action=edit&redlink=1)

Тип элемента этого класса - **"sound"**.
