# GetPedWeapon

This function tells you which weapon type is in a certain **[weapon slot](mta://reference/misc/weapon.md)** of a ped.

## Syntax

```
int getPedWeapon ( ped thePed, [ int weaponSlot = current ] )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[ped](mta://reference/misc/ped.md):getWeapon(...)*

### Required Arguments

- **thePed**: the [ped](mta://reference/misc/ped.md) you want to get the weapon type from.

### Optional Arguments

- **weaponSlot**: an integer representing the [weapon slot](mta://reference/misc/weapon.md) (set to the ped's current slot if not given).

### Returns

Returns an [int](mta://reference/misc/int.md) indicating the type of the weapon the ped has in the specified slot. If the slot is empty, it returns 0.

It should be noted that if a ped runs out of ammo for a weapon, it will still return the ID of that weapon in the slot (even if it appears as if the ped does not have a weapon at all), though [getPedTotalAmmo](mta://scripting/shared/functions/getpedtotalammo.md) will return **0**.  Therefore, [getPedTotalAmmo](mta://scripting/shared/functions/getpedtotalammo.md) should be used in conjunction with getPedWeapon in order to check if a ped has a weapon.

## Example

This example will display a player's current weapon type. In this case,a random player.

Click to collapse [-]
Server

```
-- Find a player called someguy and find his current weapon id.
local weaponType = getPedWeapon ( getRandomPlayer() )
-- If a weapon type was returned then
if ( weaponType ) then
    outputChatBox ( "someguy's current Weapon-type: " .. weaponType .. "." ) -- Display the weapon type in the chat box
end
```
