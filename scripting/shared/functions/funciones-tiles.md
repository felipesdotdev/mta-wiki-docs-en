# ES/Funciones Útiles

Esta pagina contiene una lista de las functiones que no están incluidas como de servidor or de client, pero siguen siendo útiles.

- [callClientFunction](https://wiki.multitheftauto.com/wiki/ES/callClientFunction) » Esta función permite llamar cualquier función del lado del cliente desde el lado del servidor.

- [callServerFunction](https://wiki.multitheftauto.com/wiki/ES/callServerFunction) » Esta función permite llamar cualquier función del lado del servidor desde el lado del cliente.

- [centerWindow](https://wiki.multitheftauto.com/index.php?title=ES/centerWindow&action=edit&redlink=1) » Esta función centra la ventana en cualquier resolución.

- [Check](https://wiki.multitheftauto.com/index.php?title=ES/Check&action=edit&redlink=1) » Esta funcion verifica si sus argumentos son de los tipos correctos y llama la función error si uno no lo es.

- [coroutine.resume](https://wiki.multitheftauto.com/index.php?title=ES/coroutine.resume&action=edit&redlink=1) » Fix for hidden coroutine error messages

- [doForAllElements](https://wiki.multitheftauto.com/index.php?title=ES/doForAllElements&action=edit&redlink=1) » Esta función puede ser usada para ejecutar una funcion especifica para todos los elementos de un tipo especifico.

- [dxDrawColorText](https://wiki.multitheftauto.com/index.php?title=ES/dxDrawColorText&action=edit&redlink=1) » Esta función dibuja un texto dx con soporte para códigos de color #RRGGBB.

- [findRotation](https://wiki.multitheftauto.com/index.php?title=ES/findRotation&action=edit&redlink=1) » Toma dos puntos y devuelve la dirección del punto A al punto B.

- [FormatDate](https://wiki.multitheftauto.com/index.php?title=ES/FormatDate&action=edit&redlink=1) » Formatea una fecha sobre la basándose en una cadena de formato y la devuelve.

- [getAge](https://wiki.multitheftauto.com/index.php?title=ES/getAge&action=edit&redlink=1) » Esta función la edad según el cumpleaños.

- [getAlivePlayersInTeam](https://wiki.multitheftauto.com/index.php?title=ES/getAlivePlayersInTeam&action=edit&redlink=1) » Esta función devuelve una tabla de los jugadores vivos en un equipo.

- [getCursorMoveOn](https://wiki.multitheftauto.com/index.php?title=ES/getCursorMoveOn&action=edit&redlink=1) » Esta función verifica de que forma se está moviendo el cursor actualmente.

- [getElementSpeed](https://wiki.multitheftauto.com/index.php?title=ES/getElementSpeed&action=edit&redlink=1) » Esta función permite obtener la velocidad del elemento en unidades de kph o mph.

- [getPlayerFromNamePart](https://wiki.multitheftauto.com/index.php?title=ES/getPlayerFromNamePart&action=edit&redlink=1) » Esta función permite obtener al jugador a partir de una parte de su nombre.

- [getPointFromDistanceRotation](https://wiki.multitheftauto.com/index.php?title=ES/getPointFromDistanceRotation&action=edit&redlink=1) »Encuentra un punto basado en su punto inicial, dirección y distancia.

- [getResourceSettings](https://wiki.multitheftauto.com/index.php?title=ES/getResourceSettings&action=edit&redlink=1) » Esta función devuelve una tabla con los datos del resource.

- [getTimestamp](https://wiki.multitheftauto.com/index.php?title=ES/getTimestamp&action=edit&redlink=1) » Con esta funcion se puede obtener la [marca de Tiempo Unix](http://es.wikipedia.org/wiki/Tiempo_Unix).

- [IfElse](https://wiki.multitheftauto.com/index.php?title=ES/IfElse&action=edit&redlink=1) » Devuelve uno de dos valores basado en una expresión booleana.

- [isLeapYear](https://wiki.multitheftauto.com/index.php?title=ES/isLeapYear&action=edit&redlink=1) » Comprueba si año proporcionado es bisiesto.

- [iterElements](https://wiki.multitheftauto.com/index.php?title=ES/iterElements&action=edit&redlink=1) » Devuelve un iterador para tus bucles, ahorrando tiempo en escribir ipairs( getElementsByType( type ) ), en lugar de eso escribes: iterElements( type ).

- [math.round](https://wiki.multitheftauto.com/index.php?title=ES/math.round&action=edit&redlink=1) »Redondea un número mientras  pueden establecerce el numero de decimales y el método.

- [onVehicleWeaponFire](https://wiki.multitheftauto.com/index.php?title=ES/onVehicleWeaponFire&action=edit&redlink=1) » Este código implementa un evento que provocado cuando un jugador en un vehículo dispara un arma del vehículo.

- [RGBToHex](https://wiki.multitheftauto.com/index.php?title=ES/RGBToHex&action=edit&redlink=1) » Esta funcion devuelve un string que representa el color en hexadecimal.

- [setElementSpeed](https://wiki.multitheftauto.com/index.php?title=ES/setElementSpeed&action=edit&redlink=1) » Esta funcio permite establecer la velocidad de movimiento de un elemento en unidades de kph o mph.

- [setTableProtected](https://wiki.multitheftauto.com/index.php?title=ES/setTableProtected&action=edit&redlink=1) » Protege una table y la hace de solo lectura.

- [setVehicleGravityPoint](https://wiki.multitheftauto.com/index.php?title=ES/setVehicleGravityPoint&action=edit&redlink=1) » Esta función del lado del cliente establece una gravedad de vehiculo en la dirección de una coordenada tridimensional con la fuerza especificada.

- [string.explode](https://wiki.multitheftauto.com/index.php?title=ES/string.explode&action=edit&redlink=1) » Esta función divide un string con un patrón separador dado y devuelve una tabla con las partes.

- [table.copy](https://wiki.multitheftauto.com/index.php?title=ES/table.copy&action=edit&redlink=1) » Esta función copia una tabla completa y todas las tablas dentro de ella.

- [table.map](https://wiki.multitheftauto.com/index.php?title=ES/table.map&action=edit&redlink=1) » Esta función recorre una tabla y reemplaza cada campo con lo que devuelva la función que es pasada, donde los valores de campo son pasados como primer argumento y opcionalmente más argumentos.

- [table.size](https://wiki.multitheftauto.com/index.php?title=ES/table.size&action=edit&redlink=1) » Encuentra el tamaño completo de una tabla.

- [toHex](https://wiki.multitheftauto.com/index.php?title=ES/toHex&action=edit&redlink=1) » Esta función convierte un número decimal a un número hexadecimal, como una corrección para el lado del cliente.

- [var_dump](https://wiki.multitheftauto.com/index.php?title=ES/var_dump&action=edit&redlink=1) » Esta función entrega información acerca de una o más variables usando outputConsole().

- [multi_check](https://wiki.multitheftauto.com/index.php?title=ES/multi_check&action=edit&redlink=1) » Esta función comprueba de de uno a varios elementos, util y limpia.

- [isElementInPhotograph](https://wiki.multitheftauto.com/index.php?title=ES/isElementInPhotograph&action=edit&redlink=1) » Esta función comprueba si un elemento estuvo en la foto de cámara de un jugador.
