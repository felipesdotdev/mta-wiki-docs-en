# IsPedOnFire

This function checks if the specified [ped](mta://reference/misc/ped.md) is on fire or not.

|  | This function is deprecated. This means that its use is discouraged and that it might not exist in future versions. |
| --- | --- |
| Please use isElementOnFire instead. |  |

## Syntax

```
bool isPedOnFire ( ped thePed )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[ped](mta://reference/misc/ped.md):isOnFire(...)*

**Variable**: *.onFire*

**Counterpart**: *[setPedOnFire](mta://scripting/shared/functions/setpedonfire.md)*

### Required Arguments

- **thePed**: The [ped](mta://reference/misc/ped.md) to check.

### Returns

Returns *true* if the ped is on fire, *false* otherwise.

## Example

Click to collapse [-]
Server

This example checks if a random player is on fire, and if so gives him a fire extinguisher.

```
local randomPlayer = getRandomPlayer() 
if isPedOnFire ( randomPlayer ) then 
	giveWeapon ( randomPlayer, 42, 100, true ) 
end
```
