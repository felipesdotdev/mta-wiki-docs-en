# Стандартные шрифты GUI

Здесь представлены доступные CGUI шрифты, используемые в Multi Theft Auto, которые могут быть доступны через скриптовые функции GUI [guiGetFont](mta://scripting/client/functions/guigetfont.md) и [guiSetFont](mta://scripting/client/functions/guisetfont.md).

- Доступные свойста шрифтов и их предпросмотр

- default-normal
Tahoma regular, 9px

- default-small
Tahoma regular, 7px

- default-bold-small
Tahoma bold, 8px

- clear-normal
Verdana regular, 9px

- sa-header
Diploma regular, 26px auto-scaled

- sa-gothic
Beckett regular, 47px auto-scaled
