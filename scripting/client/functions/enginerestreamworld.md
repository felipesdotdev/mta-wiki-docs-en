# EngineRestreamWorld

This function re-streams everything in the GTA world. Read [this pull request](https://github.com/multitheftauto/mtasa-blue/pull/1735) to understand what it is for.

## Syntax

```
bool engineRestreamWorld ()
```

BEFORE VERSION 1.6.0 [r22663](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=22663):

```
bool engineRestreamWorld ( [ bool includeLODs = false ] )
```

### Optional Arguments

- **includeLODs:** If is set to *true* this function will re-stream LOD models too.

### Returns

Returns *true* if the world was restreamed successfully, *false* otherwise.

## Example

This function can be used after a model (or more) is loaded with [engineLoadDFF](mta://scripting/client/functions/engineloaddff.md):

```
addEventHandler ("onClientResourceStart", resourceRoot, function ()
    engineRestreamWorld ()
end)
```
