# SvgGetDocumentXML

Gets the underlying XML document from an SVG element.

## Syntax

```
xmlnode svgGetDocumentXML ( svg svgElement )
```

### Required Arguments

- **svgElement:** The [svg](mta://reference/misc/svg.md) element you want to get the XML document of.

### Returns

- Returns an [xmlnode](mta://reference/misc/xmlnode.md) if successful, false otherwise
