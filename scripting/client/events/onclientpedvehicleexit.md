# OnClientPedVehicleExit

This event is fired when a [ped](mta://reference/misc/ped.md) has exited a [vehicle](mta://reference/misc/vehicle.md).

## Parameters

```
vehicle theVehicle, int seat
```

- **theVehicle:** The vehicle that the [ped](mta://reference/misc/ped.md) exited.

- **seat:** The number of the seat that the [ped](mta://reference/misc/ped.md) was sitting on.

## Source

The source of this event is the [ped](mta://reference/misc/ped.md) that exited the [vehicle](mta://reference/misc/vehicle.md).

## Example

This example will immediately delete any vehicle a ped exits if the vehicle's health is below 500:

```
function deleteVehicleOnExit (theVehicle, seat)
    local vehHealth = getElementHealth (theVehicle)
    if vehHealth < 500 then
        destroyElement (theVehicle)
    end
end

addEventHandler ("onClientPedVehicleExit", root, deleteVehicleOnExit)
```
