# OnClientCoreCommand

ADDED/UPDATED IN VERSION 1.6.0 [r22649](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=22649):

This event is triggered when a built-in client command is used, check [Client Commands](mta://reference/misc/client-commands.md). 

## Parameters

```
string command
```

- **command:** The command that was executed.

## Source

The source of this event is the localPlayer player element.

## Example

This example outputs the name of the command used.

```
addEventHandler("onClientCoreCommand", localPlayer, function(cmd)
    outputChatBox("Core command: "..cmd.." executed!", 255, 255, 255)
end)
```
