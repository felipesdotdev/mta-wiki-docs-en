# IsPlayerMuted

Use this function to check if a player has been muted.

## Syntax

```
bool isPlayerMuted ( player thePlayer )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[player](mta://reference/misc/player.md):isMuted(...)*

**Variable**: *.muted*

**Counterpart**: *[setPlayerMuted](mta://scripting/server/functions/setplayermuted.md)*

### Required Arguments

- **thePlayer:** The [player](mta://reference/misc/player.md) you are checking.

### Returns

Returns *true* if the player is muted and *false* otherwise.

## Example

```
someguy = getPlayerFromName ( "someGuy" )
if isPlayerMuted ( someguy ) then
   outputChatBox ( "It seems Someguy can't speak." )
end
```
