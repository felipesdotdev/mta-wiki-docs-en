# Resource : Gang Manager/getGangTag

Gets current tag of the gang.

## Syntax

```
string getGangTag ( string Gang )
```

### Required Arguments

- **Gang:** ID of the gang you wish to get tag of

### Returns

- **Tag:** Tag of the gang
