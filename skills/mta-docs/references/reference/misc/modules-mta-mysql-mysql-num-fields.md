# Modules/MTA-MySQL/mysql num fields

|  | This function is provided by the external module MTA-MySQL . You must install this module to use this function. |
| --- | --- |
|  |  |

Returns the number of fields in the given query result.

## Syntax

```
int mysql_num_fields ( MySQLResult result )
```

### Required arguments

- **result:** A valid MySQL result

### Returns

The number of fields in the given query result.
