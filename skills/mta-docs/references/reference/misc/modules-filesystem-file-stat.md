# Modules/FileSystem/file/stat

This function returns immediate statistics about this file/stream object. The output should be of same structure like that of [translator:stat](mta://reference/misc/modules-filesystem-translator-stat.md).

## Syntax

```
dictionary file:stat ()
```

## Returns

Returns a dictionary that contains the immediate file statistics.
