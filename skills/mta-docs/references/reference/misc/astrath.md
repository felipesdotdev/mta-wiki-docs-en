# Astrath

Astrath

*Astrath* is a DirectX framework for MTA:SA developed by **Magath**.  
It provides tools to create custom interfaces, animations, and other DX-based visuals.

## Client Functions

- [Astrath:createWindow](mta://scripting/client/functions/astrath-createwindow.md) – Creates a new DX-based window element

- [Astrath:createButton](mta://scripting/client/functions/astrath-createbutton.md) – Creates a DX-based button element

- [Astrath:createCheckBox](mta://scripting/client/functions/astrath-createcheckbox.md) – Creates a DX-based checkbox element

- [Astrath:createComboBox](mta://scripting/client/functions/astrath-createcombobox.md) – Creates a DX-based combobox element

- [Astrath:createEditBox](mta://scripting/client/functions/astrath-createeditbox.md) – Creates a DX-based editbox element

- [Astrath:createGridList](mta://scripting/client/functions/astrath-creategridlist.md) – Creates a DX-based gridlist element

- [Astrath:createHidden](mta://scripting/client/functions/astrath-createhidden.md) – Creates a hidden DX element (used as a parent container)

- [Astrath:createImage](mta://scripting/client/functions/astrath-createimage.md) – Draws a DX-based image

- [Astrath:createLabel](mta://scripting/client/functions/astrath-createlabel.md) – Creates a DX-based label element

- [Astrath:createMemo](mta://scripting/client/functions/astrath-creatememo.md) – Creates a DX-based multi-line text element

- [Astrath:createRadio](mta://scripting/client/functions/astrath-createradio.md) – Creates a DX-based radio button element

- [Astrath:createShape](mta://scripting/client/functions/astrath-createshape.md) – Creates a drawable rectangle element (can be used as parent)

- [Astrath:createTab](mta://scripting/client/functions/astrath-createtab.md) – Creates a DX-based tab element

- [Astrath:createTabPanel](mta://scripting/client/functions/astrath-createtabpanel.md) – Creates a container for tabs
