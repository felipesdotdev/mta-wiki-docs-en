# Hang

The sound element represents a custom sound sent to the client via the use of the file parameter inside the meta file and created either by [playSound](mta://scripting/client/functions/playsound.md) or [playSound3D](mta://scripting/client/functions/playsound3d.md).

A sound element is created using [playSound3D](mta://scripting/client/functions/playsound3d.md) or [playSound](mta://scripting/client/functions/playsound.md) and can be manipulated with the following element functions:.

- [setElementPosition](mta://scripting/shared/functions/setelementposition.md)

- [setElementDimension](mta://scripting/shared/functions/setelementdimension.md)

Sound elements can also be manipulated using the other [Client audio functions](https://wiki.multitheftauto.com/wiki/Template:Client_audio_functions).

The element type of this class is **"sound"**.
