# Teams:FFS

"For Fuck Sake" ( FFS for short ), also known as **FFS Gaming**. The first clan to introduce arena based server, with 8 concurrent gamemodes - Deathmatch, Race, Destruction Derby, Hunter, Shooter, Stuntage, Trials and Hot Pursuit.
