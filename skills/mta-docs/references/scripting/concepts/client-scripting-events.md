# Client Scripting Events

This page lists all **client-side** scripting [events](https://wiki.multitheftauto.com/index.php?search=events) that have been implemented and are available in the Deathmatch mod.

To request a event, create an issue in [our GitHub repository.](https://github.com/multitheftauto/mtasa-blue/issues)

**Server-side scripting events can be found here: [Server Scripting Events](mta://scripting/concepts/server-scripting-events.md)**
