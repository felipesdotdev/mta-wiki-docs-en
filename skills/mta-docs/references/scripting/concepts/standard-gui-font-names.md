# Standard GUI Font Names

These are the standard CEGUI fonts that are used in Multi Theft Auto and can be accessed with the GUI scripting functions [guiGetFont](mta://scripting/client/functions/guigetfont.md) and [guiSetFont](mta://scripting/client/functions/guisetfont.md).

- Available font properties and previews

- default-normal
Tahoma regular, 9px

- default-small
Tahoma regular, 7px

- default-bold-small
Tahoma bold, 8px

- clear-normal
Verdana regular, 9px

- sa-header
Diploma regular, 26px auto-scaled

- sa-gothic
Beckett regular, 47px auto-scaled
