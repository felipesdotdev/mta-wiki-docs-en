# Element/GUI font

The GUI font class represents a custom typeface which can be applied to [GUI widgets](mta://scripting/concepts/gui-widgets.md). A GUI font is created with [guiCreateFont](mta://scripting/client/functions/guicreatefont.md) and can then used as a parameter in [guiSetFont](mta://scripting/client/functions/guisetfont.md).

The element type of this class is **"gui-font"**.
