# OnPlayerPickupHit

This event is triggered when a [player](https://wiki.multitheftauto.com/index.php?search=player) hits a [pickup](https://wiki.multitheftauto.com/index.php?search=pickup).

## Parameters

```
pickup pickupHit
```

- **pickupHit**: the [pickup](https://wiki.multitheftauto.com/index.php?search=pickup) the [player](https://wiki.multitheftauto.com/index.php?search=player) hit.

## Source

The [source](mta://reference/misc/event-system.md) of this event is the [player](https://wiki.multitheftauto.com/index.php?search=player) that hit the pickup.

## Cancel effect

If this event is [canceled](mta://reference/misc/event-system.md), the player will not be able to pick up this pickup.

## Example

This example disables the use of armour pickups.

```
function armourBlock(pickup)
	if (getPickupType(pickup) == 1) then -- If it's an armour pickup
		cancelEvent() -- Cancel the event
		outputChatBox("Armour pickups are disabled.", source, 255, 0, 0)
	end
end
addEventHandler("onPlayerPickupHit", root, armourBlock)
```
