# SetServerConfigSetting

This function sets server settings which are stored in the [mtaserver.conf](mta://reference/misc/server-mtaserver-conf.md) file.

| [[{{{image}}}\|link=\|]] | Note: This function is protected by default and must be explicitly allowed in the servers acl before it can be used. |
| --- | --- |
|  |  |

| [[\|link=\|]] | Warning: "bandwidth_reduction" set to 'maximum' will cause player movement synchronization issues, on locations built outside 3000m radius from world center. |
| --- | --- |
|  |  |

## Syntax

```
bool setServerConfigSetting ( string name, string value [, bool bSave = false ] )
```

### Required Arguments

- **name :** The name of the setting. Only certain settings from [mtaserver.conf](mta://reference/misc/server-mtaserver-conf.md) can be changed with this function. These are:

- minclientversion

- recommendedclientversion

- password

- fpslimit - (0-32767)

- networkencryption - 0 for off, 1 for on (**Deprecated**)

- bandwidth_reduction - "none", "medium", "maximum" Set to maximum for less bandwidth usage (medium is recommended for race servers)

- player_sync_interval - See [Sync_interval_settings](mta://reference/misc/sync-interval-settings.md) for all *_sync_interval settings

- lightweight_sync_interval

- camera_sync_interval

- ped_sync_interval

- unoccupied_vehicle_sync_interval

- keysync_mouse_sync_interval

- keysync_analog_sync_interval

- bullet_sync

- busy_sleep_time - **ONLY USE THIS PARAMETER IF YOU ARE SURE OF WHAT YOU ARE DOING**

- idle_sleep_time - **ONLY USE THIS PARAMETER IF YOU ARE SURE OF WHAT YOU ARE DOING**

- [BETA](mta://reference/misc/beta-features.md): NEW FEATURE (BUILD: 1.6.0 [r22313](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=22313))

player_triggered_event_interval

- [BETA](mta://reference/misc/beta-features.md): NEW FEATURE (BUILD: 1.6.0 [r22313](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=22313))

max_player_triggered_events_per_interval

- [BETA](mta://reference/misc/beta-features.md): NEW FEATURE (BUILD: 1.6.0 [r22430](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=22430))

vehicle_contact_sync_radius

- [BETA](mta://reference/misc/beta-features.md): NEW FEATURE (BUILD: 1.6.0 [r22930](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=22930))

player_teleport_alert

- **value:** The value of the setting

### Optional Arguments

- **bSave:** Set to *true* to make the setting permanent, or *false* for use only until the next server restart.

### Returns

Returns *true* if the setting was successfully set, or *false* otherwise.

## Example

This example enables network encryption

```
setServerConfigSetting( "networkencryption", "1", true )
```
