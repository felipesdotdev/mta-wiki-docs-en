# ResendPlayerModInfo

This function will force the specified player to resend their mod info, triggering the [onPlayerModInfo](mta://scripting/server/events/onplayermodinfo.md) event again.

## Syntax

```
bool resendPlayerModInfo ( player thePlayer )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[player](https://wiki.multitheftauto.com/index.php?search=player):resendModInfo(...)*

### Required Arguments

- **thePlayer**: A [player](https://wiki.multitheftauto.com/index.php?search=player) object referencing the specified player

### Returns

Returns *true* if the mod info will be resent, *false* otherwise.

## Example

This example shows how to resend each players mod info during [onResourceStart](mta://scripting/server/events/onresourcestart.md)

```
addEventHandler( "onResourceStart", resourceRoot,
    function()
        for _,player in ipairs( getElementsByType("player") ) do
            resendPlayerModInfo( player )
        end
    end
)
```
