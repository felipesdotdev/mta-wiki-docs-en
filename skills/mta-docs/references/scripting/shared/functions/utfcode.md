# UtfCode

The function returns the UTF codes of the given string.

## Syntax

```
int utfCode ( string theString )
```

### Required Arguments

- **theString:** The [string](mta://reference/misc/string.md) to get the UTF code of.

### Returns

Returns an *[int](mta://reference/misc/int.md)* if the function was successful, *false* otherwise.

### Example

Click to collapse [-]
Example

```
local theString = "UTF code"
outputChatBox(utfCode (theString))
```
