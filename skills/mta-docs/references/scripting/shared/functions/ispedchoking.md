# IsPedChoking

This function checks if the specified [ped](https://wiki.multitheftauto.com/index.php?search=ped) is choking (coughing) or not. This happens as a result of weapons that produce smoke - smoke grenades, fire extinguisher and the spray can.

## Syntax

```
bool isPedChoking ( ped thePed )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[ped](https://wiki.multitheftauto.com/index.php?search=ped):isChoking(...)*

**Variable**: *.choking*

**Counterpart**: *[setPedChoking](mta://scripting/server/functions/setpedchoking.md)*

### Required Arguments

- **thePed**: The [ped](https://wiki.multitheftauto.com/index.php?search=ped) you wish to check

### Returns

Returns *true* if the ped is choking, *false* otherwise.

## Example

Click to collapse [-]
Server&Client

This example checks if a random player is choking or not, and if so displays a message in the chat box.

```
local players = getElementsByType ( "player" )
local randomPlayer = players[math.random(#players)]
if isPedChoking ( randomPlayer ) then
	outputChatBox ( getPlayerName ( randomPlayer ) .. " is choking.  Keep away from those cigarettes!" )
end
```
