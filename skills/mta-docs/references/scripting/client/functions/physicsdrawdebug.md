# PhysicsDrawDebug

Draws all static collisions and rigid bodies and other depends on debug mode.
Use it once every frame just like other dxDraw functions

## Syntax

```
bool physicsDrawDebug(physics thePhysics)
```

### Required Arguments

- **thePhysics:** physics world

### Returns

- **bool** if arguments are valid

## Example

```
physics = physicsCreateWorld()
addEventHandler("onClientRender", root, function()
  physicsDrawDebug(physics)
end)
```
