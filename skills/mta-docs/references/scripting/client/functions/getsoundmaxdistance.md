# GetSoundMaxDistance

Gets a custom [sound](https://wiki.multitheftauto.com/index.php?search=sound) max distance at which the sound stops.

## Syntax

```
int getSoundMaxDistance ( element sound )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[sound](https://wiki.multitheftauto.com/index.php?search=sound):getMaxDistance(...)*

**Variable**: *.maxDistance*

**Counterpart**: *[setSoundMaxDistance](mta://scripting/client/functions/setsoundmaxdistance.md)*

### Required Arguments

- **sound:** a [sound](https://wiki.multitheftauto.com/index.php?search=sound) element.

### Returns

Returns an *integer* of the max distance, *false* if invalid arguments where passed.

## Example

Click to collapse [-]
Client

```
local sound = playSound3D("sounds/song.mp3", 373.14, -125.21, 1001, true)

function getmaxdistanceFunc()
    outputChatBox("Max distance: " .. getSoundMaxDistance(sound))
end
addCommandHandler("getmaxdistance", getmaxdistanceFunc)
```
