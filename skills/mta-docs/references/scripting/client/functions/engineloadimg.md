# EngineLoadIMG

ADDED/UPDATED IN VERSION 1.6.0 [r21708](https://buildinfo.mtasa.com/?Author=&Branch=&Revision=21708):

This function loads an IMG container into GTA.
 

| [[{{{image}}}\|link=\|]] | Note: If you're experiencing crashes/game hangs with default values, try to adjust memory/buffer/cache sizes with engineStreamingSetMemorySize , engineStreamingSetBufferSize and/or engineStreamingSetModelCacheLimits . |
| --- | --- |
|  |  |

## Syntax

```
img engineLoadIMG ( string img_file )
```

**OOP Syntax** [Help! I don't understand this!](mta://tutorials/oop-introduction.md)

**Method**: *[EngineIMG](https://wiki.multitheftauto.com/index.php?search=EngineIMG)(...)*

### Required Arguments

- **img_file**: The [filepath](mta://reference/misc/filepath.md) to the [IMG](https://wiki.multitheftauto.com/index.php?title=IMG&action=edit&redlink=1) file you want to load.

### Returns

Returns an [IMG](https://wiki.multitheftauto.com/index.php?title=IMG&action=edit&redlink=1) element if the [IMG](https://wiki.multitheftauto.com/index.php?title=IMG&action=edit&redlink=1) file loaded, *false* otherwise.

### Examples

This example loads IMG file from directory and then prints number of files in it

```
local img = engineLoadIMG('file.img')

iprint('Number of files: ',#engineImageGetFiles(img))
```
