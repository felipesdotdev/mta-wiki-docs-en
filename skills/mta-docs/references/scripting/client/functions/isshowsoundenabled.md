# IsShowSoundEnabled

This function indicates if world [sound](https://wiki.multitheftauto.com/index.php?search=sound) IDs should be printed in the debug window or not.

| [[{{{image}}}\|link=\|]] | Note: This function only works in development mode. |
| --- | --- |
|  |  |

## Syntax

```
bool isShowSoundEnabled ( )
```

### Returns

- Returns *true* if world [sound](https://wiki.multitheftauto.com/index.php?search=sound) IDs should be printed in the debug window, *false* otherwise.

## Example

You can refer to the example below:

```
setDevelopmentMode (true)

addCommandHandler ("devdebug",
    function ()
        showSound (not isShowSoundEnabled())
    end
)
```
