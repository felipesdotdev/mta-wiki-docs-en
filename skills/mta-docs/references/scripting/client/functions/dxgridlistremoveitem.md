# DxGridListRemoveItem

Esta función sirve para eliminar un articulo/ítem de una [dxGridList](mta://scripting/client/functions/dxgridlist.md).

***Aviso: Esta es una función exportada por [Modern-Library](mta://reference/misc/modern-library.md)!***

## Syntax

```
bool dxGridListRemoveItem( element element, int index )
```

### Argumentos requeridos

- **element**: El elemento [dxGridList](mta://scripting/client/functions/dxgridlist.md).

- **index**: Un entero que representa el índice de la fila a eliminar.

## Ejemplo

```
loadstring( exports.dxLibrary:dxGetLibrary( ) )( )

--creamos una lista
lista = dxGridList( 588, 349, 351, 120 )

--Agregamos 3 columnas a la lista...
for _, c in ipairs({{'Vehiculo', 2}, {'Dueño', 2}, {'Costo', 3}}) do
   dxGridListAddColumn(lista, c[1], c[2])
end

-- Agregamos 2 filas de items, hay 3 valores en cada función porque solamente se crearon 3 columnas ↑
dxGridListAddItem(lista, 'Infernus', 'Claw', '50000') -- fila 1
dxGridListAddItem(lista, 'Sultan', 'Pand', '50000') -- fila 2

--Eliminamos la fila 1
dxGridListRemoveItem(lista, 1)
```
